PRIORITY LEXUS DIGITAL CONCIERGE — PROTOTYPE 01

FILES
- index.html — self-contained kiosk prototype. No external libraries required.

HOW TO RUN
1. Open index.html in Chrome/Edge/Silk or host it on any standard web server.
2. For the standing display, use portrait orientation and a browser/kiosk mode that hides browser chrome.
3. The interface is portrait-first for a 1080 x 1920 display but remains responsive.

WHAT IS REAL IN THIS PROTOTYPE
- Cinematic welcome/attract visual treatment
- Four primary portal buttons
- Priorities for Life interactive calculator (illustrative estimate only)
- Priority Certified animated benefits
- L/Certified animated benefits
- Guided Lexus finder
- Simulated inventory carousel
- Favorites / “Your Lexus List”
- Side-by-side compare
- Context-aware assistance requests
- Simulated CDK/Webex paging flow
- Simulated staff dashboard claim
- Automatic home reset after 90 seconds of inactivity

WHAT IS SIMULATED
- Vehicle inventory/availability/stock data
- Savings values generated by the PFL calculator
- Staff names and response timing
- Webex/CDK intercom page
- Slack/Gmail notification/logging

FUTURE INTEGRATION POINTS
- Replace local vehicles[] data with vAuto/CDK inventory API/feed
- Replace simulateRequest() with a secure backend POST to a concierge API
- Backend can trigger CDK/Webex paging, Slack, Gmail logging, SMS, or other workflows
- Add real staff claim dashboard with shared request state

IMPORTANT
Do not expose dealership telephony credentials, API keys, Slack webhooks, or other secrets inside this HTML file. Production communication integrations should be handled by a secure server-side endpoint.
